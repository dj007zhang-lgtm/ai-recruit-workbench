# 置信度计算

> 置信度不是「模型觉得自己有多准」——那是模型自评，参考价值有限。
>
> 这里用三个**可验证的客观因素**算出置信度。

## 三个信号

### 1. 证据覆盖度（权重 30%）

**定义**：有多少维度的判档能找到简历原文引用。

**算法**：
```
证据覆盖度 = 有原文引用的维度数 / 总维度数
```

判断「有原文引用」的标准：evidence 字段不为「无」，且长度 ≥6 字。

**为什么重要**：如果一半维度都是「无证据判 L0」，说明这份简历信息量不足，判档的可信度自然低。

### 2. 门槛确定性（权重 20%）

**定义**：硬门槛判定有多确定。

**算法**：
```
全部明确（pass/fail）= 1.0
有 pending（待核）= 0.5
全部 pending = 0.2
```

**为什么重要**：硬门槛大量「待核」意味着信息不足，这时得出的评级不可靠。

### 3. 判档一致性（权重 50%）

**定义**：同一份简历多次判档，结果是否一致。

**算法**（如果只判一次，用 0.6 作为默认值）：
```
一致性 = 各维度多次判档结果相同的比例
```

**为什么权重最高**：这是最硬的信号。如果同一个维度三次判出 L1、L2、L0，说明模型对这个维度没把握。

## 综合计算

```
置信度 = 0.5 × 一致性 + 0.3 × 证据覆盖度 + 0.2 × 门槛确定性
```

## 阈值与处理

| 置信度 | 含义 | 处理 |
|---|---|---|
| ≥0.75 | 高 | 可以采信判断 |
| 0.5-0.75 | 中 | 采信但标注「建议复核」 |
| <0.5 | 低 | **停下，转人工**，不给评级 |

## 低置信度的常见原因

| 原因 | 表现 | 建议 |
|---|---|---|
| 简历信息量不足 | 证据覆盖度低 | 让候选人补充材料 |
| 硬门槛大量待核 | 门槛确定性低 | 电话核实关键信息 |
| 判档摇摆 | 一致性低 | 检查评分卡锚点是否清晰 |
| 岗位描述模糊 | 维度无法对照 | 先明确岗位要求 |

## 输出格式

```
置信度：0.62（中）
  · 判档一致性 0.67（3 个维度有摇摆）
  · 证据覆盖度 0.75（3/4 维有原文引用）
  · 门槛确定性 1.0（硬门槛全部明确）
  → 建议复核「技能与专业深度」维度，该维度三次判档不一致
```

## 重要提醒

**置信度低不代表这个人不行，代表这个判断不可靠。**

所以低置信度时：
- ❌ 不要给评级（S/A/B/C）
- ❌ 不要给淘汰建议
- ✅ 明确说明「信息不足，无法判断」
- ✅ 列出需要补充什么信息
